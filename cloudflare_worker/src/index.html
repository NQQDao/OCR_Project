                        📘 Hướng dẫn kết nối Cloudflare R2 & Deploy Worker CDN:
                    
                    
    
                        
  1. Tạo Bucket trên Cloudflare Dashboard mục R2 (mặc định đặt tên: ocr-wood-storage).
    2. 
                        
  2. Tạo R2 API Token với quyền Object Read & Write, sau đó điền R2_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY vào file .env.
    3. 
                        
  3. Deploy Worker CDN: Mở terminal chạy cd cloudflare_worker rồi npx wrangler deploy.
    4. 
                        
  4. Dán URL Worker vào R2_PUBLIC_URL trong file .env để truy cập ảnh & Excel với băng thông 0đ (Zero Egress Fee)!
